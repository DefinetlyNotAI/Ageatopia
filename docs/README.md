Commands run from the repository root unless another location is specified.
Python development commands use the project virtual environment. Examples with a
version or checkpoint path require the corresponding local value.

## Historical records

The [archive](archive/README.md) preserves original specifications, implementation
ledgers, machine setup, and dated verification results. Their paths, versions,
measurements, and completion claims belong to those snapshots. They are retained
for traceability and are not installation instructions or a current support matrix.

Configuration schemas and command implementations are linked from the relevant
guides. Consult them when an archived record and a current workflow differ.
